# dbLex.pl
## Lexical Database of Polish Vocabulary
### Source XML --> CSV Export

The repository contains processing pipelines which export source XML files to CSV format. The CSV files are then read into an SQLite database, mapped to IJP PAN ontology, and exported to RDF.
The processing folder contains XSLT, XProc, and Python scripts customized for each dictionary:

- SGP (Słownik gwar polskich) - Dictionary of Polish Dialects
